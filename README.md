# Faculdade — Análise e Desenvolvimento de Sistemas

Repositório destinado à organização dos estudos, atividades e projetos desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas**.

## Organização

Os conteúdos serão separados por disciplina. Cada disciplina terá sua própria pasta, reunindo atividades, exercícios, materiais de apoio produzidos por mim e projetos relacionados.

```text
faculdade-ads/
├── disciplinas/
│   └── nome-da-disciplina/
│       ├── atividades/
│       └── README.md
├── projetos/
│   └── nome-do-projeto/
│       └── README.md
└── README.md
```

## Padrão para os arquivos

- Use nomes claros e objetivos.
- Quando possível, identifique a atividade ou o tema no nome do arquivo.
- Inclua um README em projetos maiores para explicar objetivo, tecnologias e como executar.
- Evite publicar dados pessoais, informações de colegas ou materiais cuja divulgação não seja permitida.

## Conteúdo

As pastas serão adicionadas conforme as disciplinas e os projetos forem sendo desenvolvidos. Assim, o repositório registra a evolução acadêmica sem incluir conteúdos que ainda não foram estudados.
